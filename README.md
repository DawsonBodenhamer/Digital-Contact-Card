# Digital Contact Card

Public vCard and QR code for Dawson Bodenhamer.

- `Dawson-Bodenhamer.vcf` is the contact card imported by compatible phones.
- `contact-qr.png` and `contact-qr.svg` point directly to the published vCard.
- `index.html` provides a manual download fallback.

The QR destination is:

`https://dawsonbodenhamer.github.io/Digital-Contact-Card/Dawson-Bodenhamer.vcf`
